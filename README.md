# CB module & content

The purpose of the module is to present a Community Builder list of Users with a custom presentation-template with the possibility of using/presenting all user fields from CB and Joomla. The content plugin allows you to show a CB profile in the content.


**Documentation:** settings, examples are in the [wiki](https://github.com/Tazzios/cbmodulecontent/wiki).
